# Track agent todos

Todo and checklist updates appear inline in the conversation so you can see when the agent changes
its current phase. Expand an update to review that checklist at its point in the thread.

For a persistent view, open the right panel and choose **Todos**, or press **L** while the surface
picker is open. The surface follows the latest checklist for the current thread without opening or
taking focus when the agent updates it. Completed items remain visible until a newer checklist
replaces or clears them.

Use **Open Todos** on an inline checklist to open the same thread's Todos surface directly.
