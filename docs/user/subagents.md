# Agents

The Agents panel shows work delegated to subagents, including each agent's status, latest activity, model, elapsed time, and token usage when available.

## Inspect an OpenCode agent

On web and desktop, select an OpenCode agent to open its transcript. The inspector shows its prompts, responses, reasoning, and tool calls. Tool calls and reasoning can be expanded without changing the parent conversation.

Use the back arrow to return to the roster.

Transcripts are loaded from OpenCode when you open them. If OpenCode no longer has the child session, T3 Code reports that the transcript is unavailable. Opening a transcript is read-only and does not resume the agent.
