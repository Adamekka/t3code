# Agent notifications

T3 Code can send a system notification when an agent asks a question, finishes, fails, or stops.
Web and desktop notifications work for Codex, Claude, Cursor, Grok, and OpenCode.

Open **Settings** > **General**, then turn on **System notifications**. Your browser or operating
system may ask for permission. If notifications are blocked, allow them in the browser or system
settings before turning the switch on again.

The web tab or desktop app must remain running. It can be focused, hidden, or in the background.
Clicking a notification opens the affected thread. Closing the client stops these notifications;
closed-client delivery is not supported.
